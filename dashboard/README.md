# Bitcoin Market Dashboard

The daily dashboard at [dashboard.secretsatoshis.com](https://dashboard.secretsatoshis.com/),
built from the Report Library's CSV release. It is a static site: TypeScript turns the release
into HTML at build time, and the Chart Library renderer draws the three interactive charts.

## Quick start

You need Node 24 (see `.nvmrc`).

```sh
npx --yes npm@12.0.2 ci
npm run sync:local   # copy and verify the release in ../csv
npm run dev          # local preview
```

`npm run build` writes the deployable site to `build/`. Use `npm run sync:remote` to work from
the published release instead of the local one.

## How it works

```
csv release  →  sync (hash-checked)  →  src/data.ts  →  src/render.ts  →  build/
                                           │
                                           └→  data/charts/*.json  →  chart frames
```

| Path | What's there |
|------|--------------|
| `src/data.ts` | Reads and validates the release, and builds the page data and chart payloads |
| `src/render.ts` | The page HTML: cards, tables, heatmap and chart frames |
| `src/main.ts` | Navigation, tooltips and loading each chart's data into its frame |
| `src/styles.css` | The Secret Satoshis look |
| `scripts/` | Data sync, build, browser tests and newsletter image export |
| `static/shared-chart/` | The Chart Library renderer, copied from the Chart Library |

Every input is checked against the release manifest, and a failed build leaves the previous
one in place. `build/data/manifest.json` records the report date and the hash of every input,
chart file and renderer asset.

## Updating the chart renderer

The chart frames are generated by the Chart Library. After a renderer change there, run from
the Chart Library:

```sh
.venv/bin/python scripts/sync-dashboard.py ../Bitcoin-Report-Library/dashboard/static/shared-chart
```

and commit the updated files here.

## Newsletter images

The weekly and quarterly newsletters capture sections of the built page:

```sh
npm run export:newsletter -- --report-date YYYY-MM-DD --output-dir /new/folder
npm run export:newsletter -- --profile quarterly --report-date YYYY-MM-DD --output-dir /new/folder
```

## Checks

```sh
npm run typecheck
npm test
npm run test:browser
```

The tests run against a frozen release in `tests/fixtures/`. The browser tests check the
charts, controls, layouts and that every displayed value matches the data.

## Deployment

Vercel builds each new commit with the settings in `vercel.json` and serves `build/`.
